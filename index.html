🔧 Firebase sozlash

Barcha foydalanuvchilar ma'lumotlarini real vaqtda ko'rishlari uchun bepul Firebase kerak. Bir marta sozlanadi!

1
console.firebase.google.com ga kiring → Create a project bosing → Nom bering (masalan: taskball) → Analytics o'chiring → Create project
2
Loyiha ochilgach, chap menuda Build → Realtime Database bosing → Create database → Test mode tanlang → Enable
3
Loyiha sahifasiga qayting → ⚙️ → Project settings → Pastga skroll → "Your apps" → Web ikonka </> bosing → App nomini yozing → Register app → Konfiguratsiyani ko'chirishingiz kerak
4
Quyidagi maydonlarga ko'chirilgan konfiguratsiyadan tegishli qiymatlarni kiriting:
// Ko'chirgan konfiguratsiyangiz shunga o'xshash bo'ladi: const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "taskball-xxx.firebaseapp.com", databaseURL: "https://taskball-xxx-default-rtdb.firebaseio.com", projectId: "taskball-xxx", storageBucket: "taskball-xxx.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abcdef" };
